WHATGSAP 是什麼？

GSAP 是一個 JavaScript 動畫函式庫，可以動 CSS 屬性、HTML 屬性、數字、顏色。

寫 GSAP 只要想清楚三件事：

  • 誰 要動？→ CSS 選擇器 ".box"
  • 動成怎樣？→ 屬性物件 { x: 200 }
  • 什麼時候 動？→ 馬上／排隊／捲到才動
gsap.to(".box", {   // 誰
  x: 200,             // 動成怎樣
  duration: 1
});                    // 什麼時候：馬上
📚 Wiki 對應：overview.md ・ 來源 [S1][S2]

STEP 01第一行動畫：gsap.to()

gsap.to(".box", {
  x: 260,          // = translateX(260px)
  rotation: 360,
  duration: 1       // 不寫的話預設 0.5 秒
});

一段「從 A 值變到 B 值」的動畫叫做 Tween（補間）。x、rotation 是 transform 的簡寫。

STEP 02to / from / fromTo 差在哪？

方法意思什麼時候用
gsap.to()現在的樣子 → 你指定的值一般移動、變色
gsap.from()你指定的值 → 現在的樣子⭐ 進場動畫（從透明飛進原位）
gsap.fromTo()起點、終點都自己指定要精準控制時

兩個要背的預設值：duration = 0.5 秒、ease = "power1.out"

📚 Wiki 對應：concepts/tween.md ・ 來源 [S2]

STEP 02進場動畫 + stagger

gsap.from(".card", {
  y: 80,
  opacity: 0,
  stagger: 0.12    // 每張晚 0.12 秒出發
});

stagger 讓多個目標錯開開始時間：清單、抽獎卡片、作品集縮圖一張一張出現。

STEP 03Ease：動畫的「手感」

同樣 1 秒、同樣距離，換 ease 感覺就完全不同。

gsap.to(".ball", { x: 300, ease: "back.out" });
  • 寫法："名稱.變化"，例如 "power2.out"
  • .out 開頭快、結尾慢 → 自然停下，最適合 UI 進場
  • "none" = 等速
📚 Wiki 對應：concepts/easing.md ・ 來源 [S5]（in/out 解釋為一般慣例，Wiki 已註明）

STEP 04為什麼需要 Timeline？

// ❌ 不用 timeline：手算 delay
gsap.to("#a", { x: 300, duration: 1 });
gsap.to("#b", { x: 300, duration: 1, delay: 1 });
gsap.to("#c", { x: 300, duration: 1, delay: 2 });
// 第一段改成 2 秒 → 後面 delay 全部要改 😵
// ✅ 用 timeline：自動接上
let tl = gsap.timeline();
tl.to("#a", { x: 300, duration: 1 })
  .to("#b", { x: 300, duration: 1 })
  .to("#c", { x: 300, duration: 1 });
tl.reverse(); // 一行整組倒轉

Timeline = 裝 tween 的容器。只要有 2 段以上有先後順序的動畫，就用它。

📚 Wiki 對應：concepts/timeline.md ・ 來源 [S3]

STEP 04位置參數：第三個參數決定「何時插入」

tl.to("#a", { x: 260 })
  .to("#b", { x: 260 })          // 接在後面
  .to("#c", { x: 260 }, "<")     // 跟上一段同時
  .to("#d", { x: 260 }, "-=0.5"); // 提早 0.5 秒
"<"上一段開始時
"-=0.5" / "+=1"重疊 0.5 秒 / 空 1 秒
3第 3 秒（絕對時間）
📚 Wiki 對應：concepts/timeline.md ・ 來源 [S3]

STEP 05ScrollTrigger：捲到才動

gsap.registerPlugin(ScrollTrigger); // 外掛要先註冊！

gsap.from(".section", {
  opacity: 0, y: 60,
  scrollTrigger: {
    trigger: ".section",
    start: "top center",
    markers: true   // 開發時顯示起訖線
  }
});

start: "top center" 怎麼讀？

第一個字 = 元素的哪裡，第二個字 = 畫面的哪裡。

畫面 center
.section

↑ 元素的 top 碰到畫面中線 → 開始播

QUIZ3 題小測驗（點題目看答案）

Q1. 想做「卡片從下面淡入到原位」，用 to 還是 from？

→ gsap.from(".card", { y: 80, opacity: 0 })，從指定值回到現在的樣子。

Q2. 不寫 duration 和 ease，預設是多少？

→ 0.5 秒、"power1.out"。

Q3. start: "top center" 的 top 是誰的 top？

→ 元素（trigger）的 top；center 是畫面的。
