# learning-path｜新手學習路線（Query 產物）

> Query：「一個完全沒碰過 GSAP 的人，應該照什麼順序學？」
> 讀了 [[index]] → [[overview]]、[[tween]]、[[timeline]]、[[easing]]、[[scrolltrigger]] 後整理。

1. **一行動起來**：`gsap.to()` + `duration` [S2] → [[tween]]
2. **進場動畫**：`gsap.from()` + `stagger` [S2]
3. **調手感**：換 `ease` 比較差異 [S5] → [[easing]]
4. **排順序**：timeline + `"<"` / `"-=0.5"` [S3] → [[timeline]]
5. **捲動**：ScrollTrigger 的 toggleActions → scrub → pin [S4] → [[scrolltrigger]]

這份路線就是教學簡報的章節大綱。
